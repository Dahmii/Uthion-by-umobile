# Uthion

A modern, responsive corporate website built for **Uthion**, a business consulting firm that helps organizations identify opportunities, solve business challenges, and achieve sustainable growth.

The website serves as Uthion's primary digital presence, helping potential clients discover the firm, understand its services, and connect with the business.

🌐 **Live Website:** https://uthion.com

## About the Project

Uthion needed a professional online presence that clearly communicated who they are, what they offer, and how they help businesses grow.

The goal of the project was to translate the firm's consulting services into a clear and approachable web experience while establishing a credible digital presence for potential clients discovering Uthion online.

I worked on building the website with a focus on:

- Clear communication of Uthion's services and value proposition
- Responsive layouts across desktop, tablet, and mobile devices
- Reusable and maintainable frontend components
- Consistent visual presentation across the website
- Intuitive navigation and content hierarchy
- Performance and usability

## Key Features

### Responsive Interface

The website is designed to provide a consistent experience across different screen sizes, with layouts and components adapting appropriately for desktop and mobile users.

### Service Presentation

Uthion's consulting services are structured and presented in a way that allows prospective clients to quickly understand the areas in which the firm can support their businesses.

### Business-Focused User Experience

The site's information architecture prioritizes the questions a potential client is likely to have:

- Who is Uthion?
- What does the firm do?
- How can Uthion help my business?
- How can I get in touch?

This helped guide decisions around page structure, navigation and content presentation.

### Reusable Components

The frontend is structured around reusable React components to keep the interface consistent and make future updates easier to maintain.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/Dahmii/Uthion-by-umobile.git
cd Uthion-by-umobile
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
